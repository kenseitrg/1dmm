# mm1d — 1.5D Reflectivity Synthetic Modelling Tool

Compute synthetic seismic wavefields (primaries, surface multiples, interbed
multiples) from P-velocity and density well logs using the reflectivity method,
for multiple analysis: zero-offset synthetics, angle and offset gathers,
semblance panels, and theoretical RMS-velocity event overlays.
